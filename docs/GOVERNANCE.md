# Governance

This repository is a parody project maintained by QSOL-IMC under the MIT license. Code correctness, security boundaries, and faithful documentation are not parodies.

- Changes enter through reviewable PRs. Do not merge merely because the release notes sound impressive.
- The one-line skill rule is a compatibility contract for this joke, not a claim about real Claude Skills specifications.
- The machine-generated-looking marketing is intentionally overconfident; factual engineering claims must remain checkable.
- Tests must differentiate **executed results** from proposed or inferred evidence.
- No unreviewed external runtime dependencies or cloud inference services.
- Maintain release notes and immutable provenance when cutting tagged versions.

The fictional enterprise standards committee may suggest changes, but it does not have merge permission.

## CSA-002 editorial decisions

The maintainer explicitly retains the one-line `Long Live The Queen` instruction despite its anachronism. `minimalism` as an empty `SKILL.md` is **rejected** under the one-line rule, including for satire. AI-proposed content must be clearly attributed, reviewed by a human, and must not retroactively overwrite the archived source observation. An AI suggestion to deliberately fail CI is not adopted: correctness remains a hard requirement.
